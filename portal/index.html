Connect this browser

Writes go through the GitHub API with a fine grained token that stays in this browser only. Treat it like a password.

  1. Create a fine grained token (sign in to GitHub if asked).
  2. Repository access: Only select repositories, pick chuatzeyee/Tylendar.
  3. Permissions: Contents, Read and write and Actions, Read and write.
  4. Generate it, copy it, paste it below.
